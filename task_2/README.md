# Завдання 2. Складання розкладу жадібним алгоритмом

## Задача
Покрити множину предметів мінімальною (за жадібною евристикою) кількістю викладачів —
класична задача покриття множини (Set Cover).

## Алгоритм
Клас `Teacher` зберігає ім'я, прізвище, вік, email, множину `can_teach_subjects` та
призначені предмети `assigned_subjects`.

`create_schedule(subjects, teachers)`:
1. `uncovered` — множина ще непокритих предметів.
2. На кожному кроці серед доступних викладачів обирається той, у кого
   `|can_teach_subjects ∩ uncovered|` найбільший; при рівності — наймолодший.
3. Йому призначаються лише ті предмети, що ще не покриті; вони видаляються з `uncovered`,
   викладач виключається з подальшого вибору.
4. Якщо жоден викладач не покриває жодного з решти предметів — повертається `None`
   і програма виводить повідомлення, що покрити всі предмети неможливо.

## Складність
O(k · m · s), де k — кількість обраних викладачів (≤ m), m — кількість викладачів, s — кількість предметів.
Жадібний алгоритм дає наближення з коефіцієнтом ln(n) до оптимального покриття.

## Приклад виведення
```
Розклад занять:
Наталія Шевченко, 29 років, email: n.shevchenko@example.com
   Викладає предмети: Біологія, Хімія

Дмитро Бондаренко, 35 років, email: d.bondarenko@example.com
   Викладає предмети: Інформатика, Фізика

Олександр Іваненко, 45 років, email: o.ivanenko@example.com
   Викладає предмети: Математика
```

Розбір кроків: спочатку всі кандидати з двома предметами; найменший вік — Наталія (29).
Далі серед Іваненка, Коваленка (по 2 непокриті: Математика+Фізика / Інформатика+Математика)
та Бондаренка (Фізика+Інформатика) найменший вік у Бондаренка (35). Залишається Математика —
її покриває Іваненко (45) або Коваленко (50); обирається молодший — Іваненко.

## Висновки
Усі 5 предметів покрито трьома викладачами. Якщо предмет не може викладати жоден викладач
(наприклад, «Музика»), функція повертає `None`, і виводиться повідомлення
«Неможливо покрити всі предмети наявними викладачами.»
